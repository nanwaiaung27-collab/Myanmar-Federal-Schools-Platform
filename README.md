# Myanmar Federal Schools Platform

A simple informational website for exploring online federal schools in Myanmar. The platform displays school details such as establishment year, student and teacher counts, class schedules, contact links, and available online tools.

## Overview

This project is a static web application built with HTML, CSS, and JavaScript. It presents a searchable list of schools and allows users to view each school’s information in a structured card layout.

## Features

- Search schools by name
- Display school cards with key information
- Show contact links to Telegram, Facebook, website, and YouTube
- Highlight online learning tools used by each school
- Smooth scroll-reveal animations
- Responsive design for desktop and mobile screens

## Project Structure

- index.html – Main page structure
- style.css – Styling and layout
- app.js – Main logic for rendering school cards and search behavior
- schoolsData.js – School data used by the application
